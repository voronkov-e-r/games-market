# Проект игрового интернет-магазина на python
## Стек:
- Django для фронт-части
- FastAPI для создания api и бека
- Kafka для взаимодействия первых двух

## Инструкция по запуску:
- Запустите (через docker desktop) kafka сервер на порту 9092
- Перейдите в репозиторий front (cd front в терминале) и запустите django сервер на порту 1111:
```bash
python manage.py runserver 1111
```
- Во втором окне терминала перейдите в репозиторий marketAPI (cd marketAPI) и запустите fastapi сервер на порту 2222:
```bash
uvicorn mainAPI:app --port 2222
```

Добро пожаловать на сервер! <br>
P.S. Для регистрации аккаунта можете использовать любые данные

## Общая схема взаимодействия:
API и клиентская сторона взаимодействуют друг с другом через kafka (асинхронно). Продюсер фронта делает запрос, после чего ожидает ответ и предоставляет его клиенту.

## Клиентская часть:
Часть стилизаций (только она) была сгенерирована для экономии времени.
Фронтенд состоит из двух основных частей:
- Логининга: ветка, по которой пользователь проходит регистрацию и вход. Почта и пароль нигде на сервере не хранится. Для управления сессией используются куки, что хранят только общие данные о пользователе.
- Маркета: ветка магазина. Страницы библиотеки, каталога, пополнения баланса. 

## Серверная часть:
API составляющая опирается на стандартные методы и функции. Из интересного можно отметить реализованную идемпотентность платежей и обработку возможных исключений.
